# AI Resume Skill Scanner

A Python tool that extracts skills from resume text using NLP and gives a hiring score.

## Features
- Extracts technical skills automatically from resume
- Calculates resume score based on skills match
- Generates shortlist / reject verdict

## Tech Stack
Python, Regex, NLP

## How to Run
pip install -r requirements.txt
python main.py

## Sample Output
Detected Skills: Python, AI, Data Science
Score: 8/10 -> SHORTLIST
